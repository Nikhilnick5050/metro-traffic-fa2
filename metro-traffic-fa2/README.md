# Metro Traffic Congestion — Design Thinking FA2

A website submission for the Design Thinking FA2 (Poster Presentation) assignment.

## Problem
Metro cities like Delhi and Bengaluru rely on manual surveys to understand traffic congestion. This project proposes using GPS and data models to automatically detect traffic hotspots and suggest alternate routes.

## Design Thinking Stages
1. Empathize — commuters, traffic police, city planners
2. Define — problem statement
3. Ideate — GPS data, hotspot detection, alternate routes
4. Prototype — a traffic dashboard mockup
5. Test — feedback and refinement

## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — smooth scroll and reveal animation
